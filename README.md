# TogetherPhotoBooth

A modern photo booth application for capturing, customizing, and sharing memorable moments with friends, family, and events.

## ✨ Features

* 📸 Take photos directly from the app
* ⬆️ Upload photos from gallery
* 😀 Customize photos with emojis and stickers
* 🎨 Apply filters and visual effects
* 🖌️ Interactive and customizable UI
* 💾 Save edited photos to device
* 📱 Smooth SwiftUI experience for iPhone and iPad
* ⚡ Fast and responsive photo processing

---

## 🚀 Getting Started

### Prerequisites

Before running the project locally, make sure you have:

* Xcode 15 or later
* iOS 17+ recommended
* Swift 5.9+

### Installation

Clone the repository:

```bash
git clone https://github.com/puddingrr/TogetherPhotoBooth.git
```

Move into the project directory:

```bash
cd TogetherPhotoBooth
```

Open the project in Xcode:

```bash
open TogetherPhotoBooth.xcodeproj
```

Run the app using the iOS Simulator or a physical device.

```bash
http://localhost:3000
```
